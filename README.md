# Разработка и интеграция веб-приложения с использованием Docker и Docker Compose
Этот проект представляет собой простое веб-приложение, которое использует Docker и Docker Compose, которое включает функции регистрации пользователей, авторизации через социальные сети и управление различными уровнями доступа.

## Требования

Для работы приложения необходимо установить следующие инструменты:

    Docker
    Docker Compose
    
## Инструкции по настройке

1. Клонируйте репозиторий:

` git clone https://github.com/palmistry911/web_app_docker_compose.git`

` cd web_app_docker_compose `

2. Скопируйте ` .env_example` в `.env` и настройте собственные переменные окружения:

`cp .env_example .env`

3. Запустите контейнеры через docker-compose:

`docker compose up -d`

В процессе запуска будет создан суперпользователь

Остановить проект

`docker compose down`

Доступ к приложению будет доступен по адресу

http://localhost:5000.

### Устранение неполадок

Если возникнут проблемы при настройке, убедитесь, что Docker работает корректно, и попробуйте заново построить образы с помощью команды docker-compose build.
